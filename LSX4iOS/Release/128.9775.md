# iOS 128.9775

Claude changes in this checkout add 656x368 rendering, explicit iOS resolution
configuration, AMD FSR 1.0 / NVIDIA NIS / bilinear upscaling and an Off option.
Bloodborne defaults to 360p plus FSR when no user resolution is saved, and LOD 2
is the bundled default. Existing user selections remain authoritative.
Snapdragon GSR is not offered in the UI.

The supplied candidate is builds/up8/LSX4RuntimeProbe.app in the private handoff.
Its 41 Swift inputs are equivalent to this source tree (whitespace excluded).
The new native resolution parser functions match the compiled source input;
the inherited native baseline continues to use retained objects as described
in README.md. This release does not claim a clean full-runtime rebuild.
The publication copy updates stale 640x368 hint translations to 656x368 and is
re-signed for recipient signing. Executable section payloads are preserved.

The handoff described four Swift files; the actual implementation changes three:
FullConsoleLibrary.swift, IOSManagedOptimizations.swift and LSX4GoldPages.swift.
All listed functionality is present in those files.

Focused host checks cover resolution presets, all offered upscalers, Off,
explicit overrides, native configuration precedence and Android fallback;
the parser is exercised under ASan/UBSan. Device evidence is retained separately.
No new physical performance claim is inferred from packaging or host checks.
