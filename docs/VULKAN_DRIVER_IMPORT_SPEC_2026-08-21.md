# Постановка: выбор и импорт драйвера Vulkan

> [!IMPORTANT]
> Before any device/FPS/playable measurement, run `scripts/preflight-vivo-performance-test.ps1`;
> stale Android Studio process-trackers and known profiler loads make the result invalid. See the
> mandatory [performance-test preflight](PERFORMANCE_TEST_PREFLIGHT.md).

Автор: claude. 21.08.2026. Исполнитель: codex.

## 1. Что делаем

Вместо галочки — один список выбора: **Qualcomm (по умолчанию)**,
**Mesa Turnip 26.2.1 (встроенный)** и отдельный пункт для каждой
успешно проверенной импортированной версии. Справа в той же строке находится
кнопка `+`, открывающая импорт архива. Отдельных карточек импорта и выбора
источника под списком нет.

Нейтральная подпись встроенного драйвера намеренна: точный D6/SHA из этой
сборки прошёл экранный smoke на Vivo V2546A с Adreno 840, но это свидетельство
нельзя переносить на любой другой Adreno. На текущем устройстве фактический
результат показывает уже существующая пометка `активен` либо видимая причина
fallback; отдельный длинный статус совместимости в строку не добавляется.

Позиция в динамическом списке не является идентификатором. Выбор хранится как
`system`, `bundled` или `imported:<sha256>`; старый int 0/1 остаётся только
совместимым зеркалом для миграции на предыдущие сборки.

## 2. Формат архива

Принимать общепринятый в сообществе вид: zip с описанием и одной библиотекой.
Формат — не код, его заимствование ничего не нарушает, а совместимость с тем,
что у людей уже скачано, экономит им работу.

Из описания брать: имя, версию, минимальный уровень системы, имя файла
библиотеки. Ничему из описания НЕ ВЕРИТЬ — это подсказка для показа, а не
основание для допуска.

## 3. Проверка при импорте — по возрастанию строгости

1. **Структура.** Один архив, ограничение размера, ровно одна библиотека,
   запрет путей с выходом вверх (`..`), запрет ссылок.
2. **Двоичный вид.** Это ELF, arm64, экспортирует точку входа драйвера.
   Список зависимостей не содержит ничего, чего мы не можем предоставить.
3. **Живая проба в ОТДЕЛЬНОМ процессе.** Загрузить, создать экземпляр,
   перечислить устройства, создать и уничтожить тестовое логическое устройство,
   прочитать имя и версию драйвера. Успех обязан быть отражён отдельным полем
   `logicalDeviceProbePassed`; одного имени или отображения библиотеки недостаточно.
   Это probe-контракт версии 2: записи прежнего контракта не попадают в список до
   повторного импорта и проверки на текущем устройстве.
   **Принимается только тот драйвер, который ОТВЕТИЛ.**

Проба обязана идти вне процесса игры: чужой драйвер — произвольный машинный
код, и падение при загрузке не должно уносить приложение.
Игровой процесс повторно проверяет файл, SHA, mapping, identity и необходимые
расширения, но не создаёт временный `VkDevice` перед настоящим устройством
рендерера: этот lifecycle-тест уже выполнен одноразовым процессом.

## 4. Установка и откат

- Распаковка во временный каталог → проверка → **переименование** на место.
  Никогда не писать поверх работающего файла.
- Успешная probe записывает атомарный `verified.json` внутрь content-addressed
  slot. Только slot с таким свидетельством на текущем устройстве попадает в
  список. Импорт добавляет пункт, но сам не меняет текущий выбор.
- Все ранее проверенные версии сохраняются и остаются доступны по своему SHA.
- Запись о драйвере хранит **SHA-256 файла** и результат пробы. Изменился
  файл — запись недействительна, проба повторяется.

## 5. Как не допустить молчаливого отката

Это главное требование: за сутки работы молчаливый откат трижды создавал
ложные выводы («включил галочку — вижу 60»), каждый раз стоил часа.

- **В списке выбора показывать то, что РАБОТАЕТ, а не то, что выбрано.**
  Разошлись — писать об этом прямо в списке, а не только в журнале.
- В наложении и в файле состояния: запрошено, фактически, причина отката,
  имя и версия драйвера, SHA загруженного файла.
- Отказ при импорте — видимая ошибка с причиной, а не тихий возврат к
  штатному драйверу.

## 6. Как доказывать фактический драйвер

Три независимых свидетельства, все три в отчёт:
имя и версия из свойств устройства; SHA файла; подтверждение по карте
отображений процесса, что загружен именно он.

## 7. Список несовместимостей

Предохранитель привязывать к паре **устройство + SHA драйвера**, НЕ к хэшу
сборки приложения: 21.08 хэш приложения менялся десятки раз за ночь, и
привязка к нему делала предохранитель непредсказуемым.

## 8. Защита от невозможности вернуться

Импортированный драйвер может валить приложение до экрана настроек, и человек
окажется заперт. Поэтому: N падений подряд с выбранным драйвером — автоматический
возврат на штатный, с явным сообщением почему. Без этого одна неудачная версия
делает приложение неработоспособным.

## 9. Приёмка

1. Импорт годного архива: отдельный `Mesa Turnip <версия> · <sha8>` появляется
   в списке, проба пройдена, текущий выбор не меняется, имя и версия совпадают
   с фактическими.
2. Импорт негодного архива (не ELF, не arm64, без точки входа): видимый отказ
   с причиной, ничего не установлено, прежний драйвер цел.
3. Импорт архива, который проходит проверки, но падает при пробе: отказ,
   приложение живо.
4. Выбор Qualcomm: ни одного нового вызова относительно нынешнего поведения.
5. Выбор Turnip при снятой библиотеке: видимый откат с причиной.
6. Три подряд падения с выбранным драйвером: автоматический возврат и сообщение.
7. **Неизменность:** с выбором по умолчанию сравнение до и после правки на одной
   сцене не даёт расхождения вне разброса.
