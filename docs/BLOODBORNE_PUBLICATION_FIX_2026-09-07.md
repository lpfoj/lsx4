## Что было сломано

1. Обратное копирование GPU-изображения забирало только mip0, но публиковало всю гостевую аллокацию. Неинициализированные данные младших mip-уровней и отступов повреждали память игры. В контрольном запуске Bloodborne зависала на загрузке после гостевого исключения Thread17: RIP `0x8020859c7`, недопустимая запись `[RDX-2]`.
2. После диагностического исключения повреждающей записи обнаружилось независимое падение GpuComm: `Translator::GetSrc -> V_MBCNT_U32_B32`. Операнды EXEC не обрабатывались как маска активных lanes. Дополнительно compute pipeline читал размер workgroup из runtime-слота0 вместо LogicalStage::Compute.

Диагностическое отключение readback использовалось только для установления причин. **В итоговой сборке публикация GPU-данных включена, PageManager восстановлен побайтно к исходному состоянию.**

## Итоговая правка

- Копируются все mip-уровни с их фактическими размерами, pitch и offset.
- Выход readback предварительно заполняется снимком гостевой памяти. Тилер обновляет только реально скопированные texels; отступы и неохваченные области сохраняются.
- При публикации записываются только байты, отличающиеся от сохранённого снимка. Это предотвращает перезапись нетронутых областей и более поздних CPU-записей в них. Обычные вызовы TryWriteBacking сохраняют прежнюю семантику memcpy.
- Исправлены invalidate mapped memory после завершения GPU, usage-флаги и срок жизни overflow-буферов.
- MBCNT получает EXEC через ballot; обычные маски сохраняют вычисление номера lane без зависимости от host subgroup.
- Все пути создания compute pipeline, включая async и warmup, используют правильный logical-stage runtime-слот. Версия shader binary cache повышена с32 до33.

Это общие изменения памяти и шейдерного транслятора, без проверок имени игры или производителя устройства. Настройки графики, CPU-профили, разрешение, файлы игр и сохранения вручную не изменялись. Обычные игровые автосохранения остаются возможны. Прочие изменения Gold не переносились.

## Сборка и автоматические проверки

- Оба native-target собраны успешно: PS4 —132.6с, PS5 — без изменений.

Тест не ослаблялся. Не заявляется полностью зелёный общий suite.
